# `:basic:basic_network`

> 对齐 Google [Now in Android](https://github.com/android/nowinandroid) `:core:network` 设计：
> 独立远程网络数据通信模块。包含 Retrofit / OkHttp API 契约（`ArticleApi` / `ArticleRxApi` / `NetworkApi`）、网络序列化 DTO（`ArticleData` / `LoginData` / `NetworkChangeList` / `NetworkResult`）与远程数据源抽象实现（`ArticleRemoteDataSource`）。
