# module_ui Tab 页面拆分 → module_tab

## 目标

将 module_ui 中 5 个「上方 Fragment + 下方 Tab」模式的 Activity 拆分到独立的 `module_tab` 模块。

## 拆分的 Activity（5 个）

| Activity | Tab 实现方式 |
|----------|-------------|
| AppBarActivity | Material TabLayout + ViewPager |
| FragmentTabHostActivity | FragmentTabHost + TabWidget |
| FragmentActivity1 | 自定义 LinearLayout + TextView |
| FragmentActivity2 | RadioGroup + RadioButton |
| FragmentViewPagerActivity | RadioGroup + ViewPager |

## 实施步骤

### Step 1: 创建 module_tab 模块结构

新建目录 `modules/module_tab/`，包含：
- `build.gradle.kts` — 使用 android.library + arouter + eventbus 插件
- `src/main/AndroidManifest.xml` — 注册 5 个 Activity
- `src/main/java/com/example/william/my/module/tab/TabActivity.kt` — 入口 Activity（@Route）

### Step 2: 移动源文件

从 `modules/module_ui/` 移动到 `modules/module_tab/`：

**Activity 文件**（5 个）：
- `activity/AppBarActivity.kt`
- `activity/FragmentTabHostActivity.kt`
- `activity/FragmentActivity1.kt`
- `activity/FragmentActivity2.kt`
- `activity/FragmentViewPagerActivity.kt`

**Adapter 文件**（需确认是否仅被 tab 页面使用）：
- `adapter/ViewPagerAdapter.kt`
- `adapter/ViewPagerAdapter2.kt`
- `adapter/ViewPagerFragmentAdapter2.kt`

**Utils 文件**：
- `utils/FragmentUtils.kt`（仅被 FragmentActivity1/2 使用）

### Step 3: 移动布局文件

从 `module_ui/src/main/res/layout/` 移动到 `module_tab/src/main/res/layout/`：
- `ui_activity_app_bar.xml`
- `ui_activity_fragment_tab_host.xml`
- `ui_activity_fragment_1.xml`
- `ui_activity_fragment_2.xml`
- `ui_activity_fragment_view_pager.xml`
- `ui_item_tab_host.xml`

### Step 4: 更新路由和入口

1. **RouterPath.kt** (`basic/basic_shared/.../router/path/RouterPath.kt`)：
   - 新增 `object Tab` 包含 Main、AppBar、FragmentTabHost、Fragment1、Fragment2、FragmentViewPager 路由常量
   - 移除 `RouterPath.UI` 中对应的路由常量

2. **ModuleActivity.kt** (`basic/basic_shared/.../ModuleActivity.kt`)：
   - 新增 `RouterItem("Tab", RouterPath.Tab.Main)` 入口

3. **TabActivity.kt**（新建）：
   - `@Route(path = RouterPath.Tab.Main)`
   - 继承 `RouterRecyclerActivity`
   - `buildRouter()` 返回 5 个子页面路由

### Step 5: 注册模块

1. **settings.gradle.kts**：添加 `include(":modules:module_tab")`
2. **AndroidDeps.kt** (`build-logic/convention/src/main/kotlin/AndroidDeps.kt`)：
   - 在 `configureFeatureAndroid()` 中添加 `"implementation"(project(":modules:module_tab"))`

### Step 6: 清理 module_ui

1. **UiActivity.kt**：移除 5 个 tab 页面的路由项
2. **AndroidManifest.xml**：移除 5 个 Activity 的注册

### Step 7: 更新文档

- `docs/modules.md` — 添加 module_tab 说明，更新 module_ui 说明
- `README.md` — 更新模块列表

## 验证方式

1. `./gradlew assembleDemoDebug` — 确保编译通过
2. 运行 app → 模块列表中出现「Tab」入口
3. 点击进入 Tab 模块 → 5 个子页面均正常展示
4. 返回 module_ui → 剩余 8 个 Activity 功能不受影响
