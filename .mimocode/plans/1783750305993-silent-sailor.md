# module_sample 拆分计划

## 目标
将 module_sample 按功能域拆分为 4 个独立模块，每个模块有独立入口。

## 拆分方案

### 新模块划分

| 新模块 | 包含 Activity | 包含 Service | 特殊资源 |
|--------|--------------|-------------|---------|
| `module_sync` | AsyncTaskActivity, HandlerThreadActivity, JobSchedulerActivity | MyJobSchedulerService | 无 |
| `module_service` | ServiceActivity, MessengerActivity | MyAIDLService, MyForegroundService, MyMessageService | AIDL 文件 |
| `module_component` | BroadcastActivity, ActivityResultActivity, ActivityResultActivity2, OnBackPressedActivity | 无 | 无 |
| `module_system` | NotificationActivity, PermissionActivity, TypefaceActivity | 无 | assets/fonts/juice.ttf |

### 删除
- `module_sample` 整个模块删除

## 执行步骤

### Step 1: 创建 module_sync

**目录结构**:
```
modules/module_sync/
├── build.gradle.kts
├── proguard-rules.pro
├── .gitignore
└── src/main/
    ├── AndroidManifest.xml
    └── java/com/example/william/my/module/sync/
        ├── SyncActivity.kt             (主入口)
        └── activity/
            ├── AsyncTaskActivity.kt
            ├── HandlerThreadActivity.kt
            └── JobSchedulerActivity.kt
    └── java/com/example/william/my/module/sync/service/
        └── MyJobSchedulerService.kt
```

**build.gradle.kts**:
```kotlin
plugins {
    alias(libs.plugins.nowinandroid.android.library)
    alias(libs.plugins.nowinandroid.android.arouter)
    alias(libs.plugins.nowinandroid.android.eventbus)
}

android {
    namespace = "com.example.william.my.module.sync"
    resourcePrefix("sync_")
}

dependencies {
    implementation(project(":basic:basic_lib"))
    implementation(project(":basic:basic_module"))
}
```

**AndroidManifest.xml**:
```xml
<?xml version="1.0" encoding="utf-8"?>
<manifest xmlns:android="http://schemas.android.com/apk/res/android">
    <application>
        <activity android:name=".SyncActivity" />
        <activity android:name=".activity.AsyncTaskActivity" />
        <activity android:name=".activity.HandlerThreadActivity" />
        <activity android:name=".activity.JobSchedulerActivity" />
        <service android:name=".service.MyJobSchedulerService"
            android:permission="android.permission.BIND_JOB_SERVICE" />
    </application>
</manifest>
```

**修改内容**:
- 所有类的 package 改为 `com.example.william.my.module.sync`
- RouterPath 新增 `Sync` object，路径 `/Sync/*`
- Activity 的 `@Route` 注解更新为新路径

### Step 5: 更新 RouterPath.kt

**文件**: `basic/basic_module/src/main/java/.../router/path/RouterPath.kt`

删除 `Sample` object，新增 4 个 object：

```kotlin
// 删除
// object Sample { ... }

// 新增
object Sync {
    private const val Sync = "/Sync"
    const val Main = "${Sync}/Main"
    const val AsyncTask = "${Sync}/AsyncTask"
    const val HandlerThread = "${Sync}/HandlerThread"
    const val JobScheduler = "${Sync}/JobScheduler"
}

object ServiceDemo {
    private const val ServiceDemo = "/ServiceDemo"
    const val Main = "${ServiceDemo}/Main"
    const val Service = "${ServiceDemo}/Service"
    const val Messenger = "${ServiceDemo}/Messenger"
}

object Component {
    private const val Component = "/Component"
    const val Main = "${Component}/Main"
    const val Broadcast = "${Component}/Broadcast"
    const val ActivityResult = "${Component}/ActivityResult"
    const val OnBackPressed = "${Component}/OnBackPressed"
}

object System {
    private const val System = "/System"
    const val Main = "${System}/Main"
    const val Notification = "${System}/Notification"
    const val Permission = "${System}/Permission"
    const val Typeface = "${System}/Typeface"
}
```

## 注意事项

- `PermissionActivity` 在 Manifest 中注册但无源码，需要创建空实现或从 Manifest 中移除
- `RecyclerCacheExtension` 工具类在 module_sample 中未被使用，可忽略或移动到合适位置
- `ui_divider.xml`、`ui_anim_*.xml`、`ui_selector_*.xml` 资源文件在 module_sample 中未被直接使用，可忽略
