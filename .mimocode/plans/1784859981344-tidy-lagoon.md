# 重构 module_network：拆分 OkHttp/Retrofit/Download 为独立模块

## 目标

将 OkHttp、Retrofit、Download 相关的 Activity 从 `module_network` 移到新建的 `module_okhttp` 模块中，`module_network` 保留 Ktor、HttpURL、Volley、Nano。

## 变更清单

### 1. 新建 `module_okhttp` 模块

**文件：`modules/module_okhttp/build.gradle.kts`**
```kotlin
plugins {
    alias(libs.plugins.nowinandroid.android.library)
    alias(libs.plugins.nowinandroid.android.arouter)
    alias(libs.plugins.nowinandroid.android.eventbus)
}

android {
    namespace = "com.example.william.my.module.okhttp"
}

dependencies {
    implementation(project(":basic:basic_lib"))
    implementation(project(":basic:basic_shared"))
    implementation(project(":basic:basic_repository"))
    implementation(project(":libs:lib_okhttp"))
    implementation(project(":libs:lib_retrofit"))
    implementation(project(":libs:lib_download"))
}
```

**文件：`modules/module_okhttp/src/main/AndroidManifest.xml`**
- 注册所有移入的 Activity

**文件：`modules/module_okhttp/src/main/java/com/example/william/my/module/okhttp/HttpClientActivity.kt`**
- 入口 Activity，路由 `/OkHttp/Main`
- 列出所有子 Activity 的路由链接

### 2. 移动 Activity 文件

从 `modules/module_network/src/main/java/.../network/` 移动到 `modules/module_okhttp/src/main/java/.../okhttp/`：

| 源文件 | 目标包名 |
|--------|---------|
| activity/okhttp/OkHttpActivity.kt | com.example.william.my.module.okhttp.okhttp |
| activity/okhttp/OkHttpHelperActivity.kt | com.example.william.my.module.okhttp.okhttp |
| activity/retrofit/RetrofitActivity.kt | com.example.william.my.module.okhttp.retrofit |
| activity/retrofit/RetrofitHelperActivity.kt | com.example.william.my.module.okhttp.retrofit |
| activity/retrofit/RetrofitRxJavaActivity.kt | com.example.william.my.module.okhttp.retrofit |
| activity/retrofit/RetrofitRxJavaHelperActivity.kt | com.example.william.my.module.okhttp.retrofit |
| activity/retrofit/RxRetrofitActivity.kt | com.example.william.my.module.okhttp.retrofit |
| activity/download/OkhttpDownloadActivity.kt | com.example.william.my.module.okhttp.download |
| activity/download/RetrofitDownloadActivity.kt | com.example.william.my.module.okhttp.download |
| activity/download/RxDownloadActivity.kt | com.example.william.my.module.okhttp.download |

每个文件需更新 `package` 声明和 `@Route` 路径。

### 3. 更新 RouterPath.kt

**文件：`basic/basic_shared/src/main/java/.../router/path/RouterPath.kt`**

新增顶层路由对象：
```kotlin
object OkHttp {
    private const val PATH = "/OkHttp"

    const val Main = "${PATH}/Main"

    object OkHttpLib {
        private const val OKHTTP_PATH = "${PATH}/OkHttpLib"
        const val OkHttp = "${OKHTTP_PATH}/OkHttp"
        const val OkHttpHelper = "${OKHTTP_PATH}/OkHttpHelper"
    }

    object Retrofit {
        private const val RETROFIT_PATH = "${PATH}/Retrofit"
        const val Retrofit = "${RETROFIT_PATH}/Retrofit"
        const val RetrofitHelper = "${RETROFIT_PATH}/RetrofitHelper"
        const val RetrofitRxJava = "${RETROFIT_PATH}/RetrofitRxJava"
        const val RetrofitRxJavaHelper = "${RETROFIT_PATH}/RetrofitRxJavaHelper"
        const val RxRetrofit = "${RETROFIT_PATH}/RxRetrofit"
    }

    object Download {
        private const val DOWNLOAD_PATH = "${PATH}/Download"
        const val OkHttpDownload = "${DOWNLOAD_PATH}/OkHttpDownload"
        const val RetrofitDownload = "${DOWNLOAD_PATH}/RetrofitDownload"
        const val RxDownload = "${DOWNLOAD_PATH}/RxDownload"
    }
}
```

从 `RouterPath.Network` 中删除 OkHttp、Retrofit、Download 子对象。

### 4. 更新 module_network

**文件：`modules/module_network/build.gradle.kts`**
- 移除 `lib_okhttp`、`lib_retrofit`、`lib_download` 依赖

**文件：`modules/module_network/src/main/AndroidManifest.xml`**
- 移除所有 OkHttp、Retrofit、Download 相关的 Activity 注册

**文件：`modules/module_network/.../NetWorkActivity.kt`**
- 移除 OkHttp、Retrofit、Download 的路由链接
- 新增 `module_okhttp` 入口的路由链接（或保留为独立模块入口）

### 5. 更新 settings.gradle.kts

**文件：`settings.gradle.kts`**
- 新增 `include(":modules:module_okhttp")`

### 6. 更新文档

**文件：`docs/modules.md`**
- 新增 `module_okhttp` 模块说明
- 更新 `module_network` 模块说明（移除 OkHttp/Retrofit/Download 行）

**文件：`docs/libs.md`**
- 无需修改（libs 层不变）

**文件：`AGENTS.md`**
- 如有模块数量描述需更新

## 执行顺序

1. 创建 `module_okhttp` 目录结构和 build.gradle.kts
2. 移动 10 个 Activity 文件到新模块，更新 package 和 @Route
3. 创建 `module_okhttp/HttpClientActivity.kt` 入口
4. 更新 RouterPath.kt
5. 更新 module_network（删除移走的内容）
6. 更新 settings.gradle.kts
7. 更新文档（modules.md, AGENTS.md）
8. 清理 module_network 中残留的空目录

## 验证

1. `./gradlew :modules:module_okhttp:assembleDebug` 编译通过
2. `./gradlew :modules:module_network:assembleDebug` 编译通过
3. 检查所有 @Route 路径唯一性
