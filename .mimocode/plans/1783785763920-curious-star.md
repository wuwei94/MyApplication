# AnimatorActivity 拆分计划

## 目标

删除 `AnimatorActivity`，拆分为 4 个独立 Activity，每个聚焦一个属性动画 API 概念。

## 变更概览

| 操作 | 文件 |
|------|------|
| 删除 | `AnimatorActivity.kt` |
| 新增 | `ObjectAnimatorActivity.kt` |
| 新增 | `AnimatorSetActivity.kt` |
| 新增 | `ValueAnimatorActivity.kt` |
| 新增 | `KeyframeActivity.kt` |
| 修改 | `RouterPath.kt`（Anim 对象） |
| 修改 | `AndroidManifest.xml` |
| 修改 | `AnimActivity.kt`（buildRouter） |
| 修改 | `docs/modules.md` |

## 路由变更

```kotlin
// 删除
```

## 新 Activity 设计

### 1. ObjectAnimatorActivity

- **路由**: `/Anim/ObjectAnimator`
- **基类**: `BasicImageActivity`（复用，点击图片触发动画）
- **演示内容**:
  - Alpha — 透明度渐变（1→0→1）
  - Rotation — 360° 旋转
  - ScaleX — 缩放（1→0.5→1）
  - TranslationX — 水平平移
- **交互**: 每次点击切换一种动画（`index % 4` 循环）
- **注释重点**: `ObjectAnimator.ofFloat()` 的属性名参数、`setDuration()`、`setRepeatCount()`

### 2. AnimatorSetActivity

- **路由**: `/Anim/AnimatorSet`
- **基类**: `BasicImageActivity`
- **演示内容**:
  - `playSequentially()` — 顺序播放
  - `playTogether()` — 同时播放
  - `AnimatorSet.Builder` — `play(a).with(b).before(c)` 精细编排
  - `AnimatorListenerAdapter` — 替代 AnimatorListener，减少空方法
- **交互**: 每次点击切换一种组合方式（`index % 3` 循环）
- **注释重点**: `playSequentially` vs `playTogether` 的区别、Builder 的链式编排

### 3. ValueAnimatorActivity

- **路由**: `/Anim/ValueAnimator`
- **基类**: `BasicImageActivity`
- **演示内容**:
  - `ValueAnimator.ofFloat()` + `addUpdateListener` 手动更新 View 属性
  - 插值器对比（`when` 分支切换，每个分支带注释说明公式）:
    - `LinearInterpolator` — 匀速
    - `AccelerateInterpolator` — 加速
    - `DecelerateInterpolator` — 减速
    - `AccelerateDecelerateInterpolator` — 先加速后减速
    - `BounceInterpolator` — 弹跳
    - `OvershootInterpolator` — 过冲
    - `AnticipateInterpolator` — 回拉
  - `ViewPropertyAnimator` — `view.animate().translationX(400f).alpha(0f).setDuration(1000).start()` 链式调用
- **交互**: 前半段点击切换插值器，最后一种是 ViewPropertyAnimator
- **注释重点**: 每种插值器的数学公式、`ViewPropertyAnimator` vs `ObjectAnimator` 的选择场景

### 4. KeyframeActivity

- **路由**: `/Anim/Keyframe`
- **基类**: `BaseVBActivity<AnimationActivityKeyframeBinding>`（需要自定义布局）
- **布局**: 一个 ImageView + 多个按钮，每个按钮触发一种演示
- **演示内容**:
  - `PropertyValuesHolder` — 同时对 scaleX 和 scaleY 做动画（替代多个 ObjectAnimator）
  - `Keyframe.ofFloat()` — 关键帧动画（自定义中间状态，如 0°→90°→180°→270°→360°）
  - `PropertyValuesHolder.ofKeyframe()` — 关键帧 + PropertyValuesHolder 组合
  - `ObjectAnimator.ofPropertyValuesHolder()` — 用 PropertyValuesHolder 驱动动画
- **交互**: 多按钮，每个按钮触发一种演示
- **注释重点**: PropertyValuesHolder 的优势（一次计算多个属性）、Keyframe 的 `fraction` 和 `value` 概念

## 实现步骤

### Step 1: 更新路由常量

修改 `RouterPath.kt` 的 `Anim` 对象：
- 删除 `const val Animator`
- 新增 `ObjectAnimator`、`AnimatorSet`、`ValueAnimator`、`Keyframe`

### Step 2: 创建 ObjectAnimatorActivity

- 创建 `ObjectAnimatorActivity.kt`，继承 `BasicImageActivity`
- 实现 4 种属性动画，点击循环切换
- 参考原有 `AnimatorActivity` 的 1-4 方法，精简注释

### Step 3: 创建 AnimatorSetActivity

- 创建 `AnimatorSetActivity.kt`，继承 `BasicImageActivity`
- 实现 `playSequentially`、`playTogether`、`Builder` 三种组合
- 使用 `AnimatorListenerAdapter` 替代 `AnimatorListener`

### Step 4: 创建 ValueAnimatorActivity

- 创建 `ValueAnimatorActivity.kt`，继承 `BasicImageActivity`
- 实现 ValueAnimator + 7 种插值器（`when` 分支，非连续赋值）
- 末尾添加 `ViewPropertyAnimator` 演示

### Step 5: 创建 KeyframeActivity

- 创建 `KeyframeActivity.kt`，继承 `BaseVBActivity<AnimationActivityKeyframeBinding>`
- 创建 `anim_activity_keyframe.xml` 布局（ImageView + 3 个按钮）
- 实现 PropertyValuesHolder、Keyframe、组合演示

### Step 6: 删除 AnimatorActivity

- 删除 `AnimatorActivity.kt`
- 从 `AndroidManifest.xml` 移除注册

### Step 7: 更新入口和文档

- `AnimActivity.buildRouter()` 更新路由列表
- `AndroidManifest.xml` 注册 4 个新 Activity
- `docs/modules.md` 更新模块文档
